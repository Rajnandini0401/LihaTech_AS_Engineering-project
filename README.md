# A S Engineering Work ⚙️

Official website for **A S Engineering Work** (Jakhinwadi, Karad, Satara) — Precision stainless steel manufacturing (SS Rings, Bushings, Pump Sleeves & Custom Components).

---

## 🚀 Quick Start (Run Locally)

Run the project with a local dev server:

```bash
# Using Node.js (Recommended)
npx -y serve client -p 5173
```
Then open `http://localhost:5173` in your browser.

> *Alternatively, open `client/index.html` directly or with VS Code Live Server.*

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3, ES6 JavaScript
- **Libraries**: [Swiper.js](https://swiperjs.com/) (3D Coverflow slider), [FontAwesome 6](https://fontawesome.com/)
- **Design**: Fully responsive, dark industrial theme, smooth micro-interactions
